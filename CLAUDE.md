## Code Style Guidelines

- HTML: Follow semantic HTML5 standards
- CSS: Use CSS variables for theming (--wp--preset colors/spacing)
- JavaScript: ES6+ syntax preferred
- Naming: Use descriptive kebab-case for file names, camelCase for JS variables
- Formatting: 2 space indentation, no trailing whitespace
- Error handling: Use try/catch blocks for async operations
- Imports: Group imports by type (core, components, utilities)
- Responsive design: Use responsive units (rem, %, vw/vh) for layouts

## Repository Structure

- `/code`: Contains website files and assets
- `/docs`: Documentation
- `/specs`: Specifications and requirements
- `/prompts`: Claude prompts used in development
